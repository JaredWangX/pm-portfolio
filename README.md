# 王稼瑞 · AI 产品经理作品集

公开地址：https://jiaruiwang13.github.io/pm-portfolio/

Wanso 与 ONENTRA 两个产品案例。每个案例按照背景、职责、产品判断、架构、用户流程、原型、验证与路线图展开；首页的需求文档可以直接打开阅读。使用原生 HTML、CSS、JavaScript，通过 GitHub Pages 从 main 分支根目录发布。

## 原型与案例

- **个人优势**依据本人简历和自我介绍，说明技术、产品、协作与 AI 落地经验。
- **Wanso 手机原型**：`prototypes/wanso/` 使用 iOS 客户端画面回放搜索、推荐、店铺总结、菜单、同店比价、探索和个人设置。左右滑动可切换餐厅，店铺内可上下滚动。页面顶部可以打开完整目录。使用历史菜单和本地示例响应，下单按钮指向各店的平台详情页。
- **ONENTRA 桌面演示**：`prototypes/onentra/` 取自公开工作台。侧栏入口可打开各自录制的页面，对话资源选择、数据库查询、定时任务和文件预览也有对应的结果画面。在线入口指向当前功能。
- 原型会在新画面准备好后切换。店铺详情和文件预览的返回操作保留来源页面，播放流程需要手动启动。

## 可以体验什么

- **Wanso**：`demos/wanso/` 是可操作的网页版，沿用原移动应用的蓝色界面、首页、探索、收藏与个人中心。模型服务可用时支持输入预算和忌口、连续追问、查看菜单和确认餐费。界面可切换越南语和中文。
- **ONENTRA**：桌面画面取自现有公开 AI 工作平台；可以在弹窗或独立网页进入工作台，配置资源、发起对话并查看交付文件。
- **产品文档**：两份需求文档按价值判断、需求描述、流程设计、模型选型、Prompt 工程、评测数据集、评测体系、效果保障、功能说明九步组织；包含用户与系统流程图、需求编号、接口合约、验收用例及灰度回滚。已记录事实与目标门槛分开说明。
- **产品复盘**：选餐推荐如何有据可查，以及正文与附件如何联合验收，两篇记录均来自本项目。
- **个人介绍与联系**：本人确认的教育、实习、兴趣特点及求职状态。首页与两个案例末尾均有真实邮箱、复制邮箱与邮件应用入口；本站不声称代发邮件。
- **背景动画**：首页与案例页使用蓝色光影和玻璃表面。首页背景在离开首屏后停止绘制。动效可暂停，并遵循系统的减少动态效果设置。

## Wanso 模型与数据

网页调用现有 HTTPS 网关的 `POST /api/wanso`。服务器模块位于 `server/wanso.mjs`；它从受限的采集菜单生成提示，调用服务器本机模型接口，再按菜单 ID 回填名称与价格。API Key 只从服务器环境指定的文件读取，不进入网页或 Git 仓库。接口限制消息长度、同时执行数和每分钟请求数，失败返回可重试状态。

`demos/wanso/catalog.json` 当前有 5 家店、57 项菜单：胡志明市保留 McDonald’s 和 Bamysu 的 27 项采集样例；河内从本地历史备份恢复 3 家店、30 项河粉、炒饭及素食餐品。河内原采集日期未确认，只导入数值价格与原始价格文本一致的记录。切换城市会开始新对话，服务器只允许返回当前城市的菜单 ID。这些是演示数据，不能代表实时价格、营业状态、优惠、运费或过敏安全。平台链接进入平台首页，不会代替用户创建订单。没有同款图片的餐品用商家文字标识，避免拿其他菜品的图片误导用户。

Wanso 原生应用原先使用的 API 域名当前不可用。本仓库接入的是作品集网页版；没有更换原生应用的登录、订单或生产数据库。

## 本地预览与验证

运行 `python3 -m http.server 8080` 后打开 http://127.0.0.1:8080/ 。静态内容可预览；公网模型的 CORS 只允许配置的公开站点来源。部署后请从 GitHub Pages 的实际 URL 测试模型。

基础校验：`node server/wanso.test.mjs`。桌面与移动端的截图、模型连续追问和失败恢复记录见本次开发的本地验收目录；截图不作为网站源码依赖。

作品集交互回归：安装 Python Playwright 和 Chrome，启动 `python3 -m http.server 8765`，再执行 `python3 tests/portfolio_smoke.py`。覆盖播放/暂停/恢复、九条流程、65 个页面、图片失败重试、弹窗焦点、复制邮箱和 320–1440 宽度。也可通过 `PORTFOLIO_URL` 指定预览地址。它不向外部平台提交订单或发送邮件。

## 服务端部署

将本仓库 `server/wanso.mjs` 与 `demos/wanso/catalog.json` 放在同一相对目录结构。现有 Node 网关在 `/api/wanso` 和 `/api/wanso/status` 路径调用导出的 `wansoRoute(request, env)`；其余 API 仍交给原工作台处理。

服务环境需要：

- `WANSO_MODEL_ORIGIN`：服务器可访问的 OpenAI 兼容模型来源，默认 `http://127.0.0.1:8000`。
- `WANSO_MODEL_KEY_FILE`：仅服务器可读的现有模型密钥文件路径。
- 模型服务名：`qwen3.8-27b`。

`GET /api/wanso/status` 会实际检查模型列表。更新模块后需要重载 Node 网关；无需重启模型或其他服务。

恢复的数据是历史采集记录，不是原生产数据库全量恢复。原有两平台备份保留在本机；GrabFood 价格单位尚未核实，未接入演示。

参考研究与本次验收范围见 [docs/reference-study.md](docs/reference-study.md)。

### 整页玻璃改版（2026-11-23）

首页由 `home.css` 管理新的暖白玻璃体系：个人介绍 → 电脑与手机的双设备体验 → 两份案例 → 完整需求/复盘文档 → 个人优势 → 教育实践 → 联系。两台设备同时可见，窄屏优先呈现手机。选择场景会切换真实原型页面，手机与电脑互不干扰；首页设备默认静止供访客操作，完整评审页仍可播放演示。

手机展开保留当前页面，宽度优先保证可读性；高度不足时可以在窗口中滚动，关闭按钮固定可达。Wanso 第四个导航已经修正为个人中心；新增的个人中心、订单偏好、应用设置直接取自本机 Android 应用，并标明实际页面来源。没有把原生账号或系统设置虚构成已接入的网页功能。

经历改成可展开的完整记录；全部原有职责、验证口径、教育与联系信息保留。新版没有重新生成模型、迁移数据或修改 Talos 仓库。
