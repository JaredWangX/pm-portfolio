# 王稼瑞 · AI 产品经理作品集

Wanso 与 ONENTRA 两个案例，包括问题定义、我的职责、需求规则、交互证据、验证结果和后续路线图。网站通过 GitHub Pages 从 main 分支根目录发布。

- Wanso 演示采用 iPhone 17 Pro 模拟器运行本地 iOS 应用时的越南语录屏与界面截图。录屏保存在本站，支持暂停、上滑查看用餐场景、从底部导航进入选餐首页及打开城市选择。早期设计稿与费用试算在案例页单独标明。
- ONENTRA 的桌面实图来自现有 AI 工作平台。访客可直接打开原工作台操作，查看知识笔记引用和只读数据库查询。downloads 目录包含实测工作簿和面试 PDF。
- 背景为程序渲染的暖金色折纹，支持手动暂停和系统减少动态效果设置。无 WebGL 时使用同场景的静态图与缓慢位移。

使用原生 HTML、CSS 与 JavaScript。本地预览可运行 `python3 -m http.server 8080`，在浏览器打开本地 8080 端口。
