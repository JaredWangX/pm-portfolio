# 王稼瑞 · AI 产品经理作品集

面向面试官的两个产品案例。Wanso 记录越南外卖选餐、同店比价及三轮内测。ONENTRA 介绍企业 AI 工作平台的资料引用、经营报表和文件验收。

本站使用原生 HTML、CSS 和 JavaScript，通过 GitHub Pages 从 main 分支根目录发布。首页的一部手机支持切换两个项目、分步点按和暂停自动演示。两个案例页提供原型实图、需求节选、验证记录与路线图。downloads 中提供面试 PDF 与 ONENTRA 实测工作簿。

本地预览可运行 `python3 -m http.server 8080`，然后打开浏览器访问本地 8080 端口。
