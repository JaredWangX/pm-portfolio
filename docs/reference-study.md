# 参考站研究与本次改动

研究时间：2026-11-22。参考：https://www.liyanai.com/#work 。学习信息组织、入口层级和原型评审方式，本站的案例内容、图片与代码来自自己的项目。

| 页面或入口 | 已查看的内容与交互 | 本站应用方式 |
| --- | --- | --- |
| 首页与导航 | 个人介绍、优势、项目、文章、兴趣、联系；对应锚点跳转 | 保留作品集介绍、方法、项目和资料，将自己的需求文档作为独立入口 |
| 三个“快速查看” | 项目摘要、角色、结果及进入完整案例 | 两个项目各有快速预览和完整案例 |
| 三个案例详情 | 产品问题、决策、验证指标、角色说明、项目展示、前后案例链接 | 两份案例补充架构、用户流程、需求验收与后续路线图 |
| 四篇文章弹窗 | 打开阅读、关闭返回当前滚动位置 | 用两份真实项目 PRD 节选供面试官阅读，保留返回焦点与关闭行为 |
| 流调原型评审页 | 工作台、通话流调、传播链；正常、处理中、异常、人工接管 | 借鉴“流程 + 状态 + 文档”组织；Wanso 增加真实等待、失败保留输入、重试与停止 |
| 胸牌原型评审页 | 身份、任务、定位、支援；待命、执行、到位、网络状态 | 关键状态可见，流程中有反馈；自己的产品仍保持原有界面与业务逻辑 |
| 兴趣与联系 | 画廊前后切换、兴趣快捷问答、联系弹窗 | 不添加未经提供的个人经历或联系方式 |
| AI 版我 | 展开、预设问题、回答、关闭 | 本轮优先完成真实产品的模型交互，没有添加个人履历聊天分身 |
| 外部营销产品 | 案例中可看到产品入口；直接访问存在可用性问题 | 只能确认公开入口，未登录或检查其内部付费功能 |

## 本次落地

1. Wanso 用可操作的网页替换包含空白加载卡片的原生录屏。保留原应用的移动信息结构与蓝色主题。
2. 连接现有 A100 模型，后台校验菜单 ID 后回填价格；真实支持预算修改与连续追问。
3. 食物场景素材来自原项目，菜单图片本地化；不将其他餐品图片标作当前推荐的实物图。
4. 两个案例增加产品架构、用户流程、触发场景与验收标准。ONENTRA 的单次测试数字放回验证章节，不作为项目整体价值的唯一标题。
5. 需求文档在首页可直接打开。演示、完整案例和下载材料各有明确入口。

## 已验证

- 首页、两个案例和 Wanso 演示，在 1440、1024、768、390 宽度下无横向溢出、可见破图或脚本异常。
- 打开与关闭快速预览、需求文档、移动导航、菜单和城市说明。
- 实际模型连续两轮：预算 60,000、不吃鸡肉，提供候选；改为 30,000 后推荐 27,000 的菜单条目。
- 收藏、偏好选择、确认餐费；接口失败后保留原问题并提供重试。
- 服务端输入校验、伪造菜单 ID 排除、重复候选去重，以及价格由菜单回填。
