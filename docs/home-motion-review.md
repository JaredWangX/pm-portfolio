# 首页动效调整

后续全站表面反光已更新为斜向玻璃亮面，案例页也复用鼠标柔光；当前实现与验证见 [全站玻璃细节与交互复核](glass-details-review.md)。下面保留首页动效首次调整的记录。

范围仅为首页开场、背景与悬停反馈，保留现有蓝色配色、文案、产品窗口、案例链接和目录。项目页及两篇需求文档未改动。

## 动效分工

- 开场：标题两行先后进入，介绍与按钮随后出现，强调文字下方的细光带展开。约 1.3 秒结束，只执行一次；直接打开锚点、恢复滚动位置或动效脚本较晚抵达时不重新隐藏内容。
- 背景：移除连续曲线和沿线亮点，改为鼠标驱动的蓝色、浅青色与白色柔光。前层、深层和高光采用不同的收敛速度；移动时形态延展，停下后逐渐稳定。只在需要更新时绘制，不持续自动循环，不新增 WebGL 上下文。
- 交互：卡片使用局部高光，鼠标移动仅改变高光的 transform；按钮、链接箭头和阅读入口使用一致的短反馈。产品 iframe 容器不旋转、不随滚动位移。
- 阅读：正文不设置滚动淡入，不重复隐藏或重播。背景离开首屏、标签页不可见、用户暂停或光影已经稳定时停止绘制；画布分辨率限制在 150 万像素内。

GSAP 3.13.0 沿用现有工作平台的本地 vendor 文件，保留原始许可证头；页面不依赖外部 CDN。新增脚本和样式只由首页加载。减少动态效果时移除卡片高光层、保留静态背景，并禁用背景播放按钮。触屏设备显示静态背景，不截获滑动手势；按钮明确显示“静态背景”。GSAP 加载失败时正文、导航、作品和背景仍可用。

## 验证

记录保存在忽略目录 `work/home-motion/`。Talos 截图 SOP 检查桌面和手机首屏，以及开场的 8 帧序列；实际查看了这些截图与卡片悬停截图。首次启动截图时本地预览服务未运行，启动项目已有预览服务后重新检查通过。

Chrome 320、390、768、1024、1440px 检查无横向溢出。开场结束可见性、暂停／播放、离屏暂停、高光移动、快速上下滚动位置、动态切换减少动效和直接锚点访问均通过，未报告脚本错误。原有小标题与上方眉标的接近关系用于分组，本次保留，没有因检查提示改变正文排版。

Design Taste 门禁返回 `GATE: OFF (no build active)`，不记为门禁完整通过。此处为既有首页的局部动效更新，未启动整站重构。未做真实低端安卓设备的性能测试，浏览器视口检查不等同于真实硬件帧率保证。


## 鼠标背景复核

本次鼠标背景记录位于 `work/pointer-background/`。实际对比默认、鼠标右侧和左侧三张桌面截图。检查鼠标移动后画布像素发生变化，稳定后不继续绘制；暂停时移动鼠标不改变画布，恢复后重新响应。离屏停止、动态切换减少动效、触屏静止及 320–1440px 阅读检查通过。初版测试把主动切换视口造成的位移也累加为 CLS，已改为在切换视口前记录初始加载的指标，不将测试调整窗口产生的位移作为页面加载结果。

桌面 Chrome 的两秒连续指针移动采样：初始 CLS 为 0，帧间隔 P95 为 16.8ms，没有超过 50ms 的采样帧。该结果仅代表当前测试环境，不作为低端真机性能保证。
