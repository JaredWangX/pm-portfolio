# 全站玻璃细节与交互复核

本次范围为首页、Wanso 与 ONENTRA 案例、两篇需求文档、两篇复盘，共七个阅读页面。保持既有蓝色主调、文字、产品截图、录像、原型和在线产品链接。通过比较 Git 原稿与现稿，确认七页的正文、链接、图片、视频来源与 iframe 地址均未变动。

## 设计分工

- 首页沿用已经确认的鼠标柔光背景。原来的圆形卡片光斑由共享的斜向反光替代，细高光连接卡片上下边缘；卡片本身不倾斜、不位移、不缩放。
- 项目介绍、个人优势、实践和联系卡片统一玻璃边缘、蓝色深度与阴影；章节标题补充层叠图形；文档入口使用完整卡片边界，流程概览以连接节点呈现。
- 案例页将旧的循环曲面背景替换为与首页相同的鼠标柔光。产品截图展示框加入浅网格底纹，流程、职责和验证数据使用各自清晰的视觉层级。
- 阅读页统一目录选中态、流程图底板、表格表头、规则节点和编号。正文保持稳定的浅底，不将动画放在段落背景上。

## 交互约束

`glass-details.js` 同一时刻仅激活一个表面。嵌套展示框共用外层反光，装饰层不接收点击或焦点。指针坐标每帧最多提交一次，只改变装饰层的 transform；CSS 负责短暂收敛，指针停止后无持续 JavaScript 绘制循环。滚动、窗口失焦、调整窗口、进入产品 iframe、页面隐藏时清除高光，防止旧坐标滞留。

触屏和系统减少动态效果模式不显示反光。减少透明度模式使用实色表面。键盘导航保留独立焦点描边。未引入新依赖；首页 GSAP 仅保留既有入场，其他页的表面交互使用原生浏览器 API。
