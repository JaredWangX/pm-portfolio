## 视觉方向

以用户指定的蓝色为主，主按钮使用 #3B82F6；正文使用深蓝，次要文字保持足够对比。首页改用低不透明度的透明面板、24–26px 背景模糊、内侧高光和柔和投影。背景保留可辨认的蓝色曲面与弧线，在卡片内被模糊，用来显示透光关系。没有把文字一起模糊，也没有添加水波纹。

参考并实际打开了以下来源。只研究材质、层级与可读性，没有复制代码、图片或品牌效果：

- [Website Glass](https://websiteglass.com/)：观察背景内容穿过玻璃区域后的折射与模糊，区分透明材质和单纯的浅色填充。
- [Remember Style 的 Glassmorphism 示例](https://remember.style/glassmorphism)：观察背景光影、低透明度面板、边缘高光和前景文字的关系。
- [Microsoft Acrylic](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic)：参考透明度、模糊、材质层级与可读性原则。
- [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)：参考界面材质对前后层级的表达。

两种设备共用标题、场景切换、屏幕开始位置和外框系统。移除了电脑卡片的 sticky 偏移，保留电脑与手机各自的自然屏幕比例。首页正文为 17–18px，按钮与导航 14–16px，手机正文一般为 15–16px；小标签保留较小字号以维持层级。

桌面保留双设备并排；窄屏按手机优先纵向排列。平板上的首屏标题改单栏，避免末字孤立。原有项目经历、个人优势、四篇文档、原型档案和联系邮箱均保留。案例和文档页面同步蓝色材质，长篇正文采用较稳定的浅色阅读面。

动画采用背景曲面的缓慢位移、首次进入和控件反馈；背景可暂停，并遵循 prefers-reduced-motion。没有新增外部字体、动画框架或运行时依赖。

## Wanso 的实际功能

首页与 Wanso 案例内的手机改用 demos/wanso，而非只有图片热点的查看器。原始截图原型单独保留为档案。

- 可输入选餐问题，调用已有 Qwen 接口；连续追问带入上下文、日常忌口和默认预算。
- 可切换胡志明市、河内，查看采集餐厅、筛选菜单、排序、搜索和选择餐品。
- 可增减份数、核对餐费、收藏及取消收藏，并在收藏页继续操作。
- 比价可修改两平台的餐品单价、配送费、优惠与共同份数；结果即时计算，优惠超过金额时总计不低于零。
- 个人中心可编辑本机显示名称、口味偏好、默认预算、排序、语言与显示主题。
- 选餐历史可恢复继续对话；删除历史和清除本机数据均需再次确认。
- 展开手机使用同一套应用。收藏、偏好和历史保存在同源浏览器存储中；关闭和 Escape 按弹窗层级工作。
- 页面内容在手机内部滚动，顶部操作与底部四个导航持续可达。嵌入手机打开弹层时，父页面会确保设备位于可见范围，避免按钮被外层导航遮挡。

边界仍明确：菜单来自历史样例；比价按输入费用计算，不是实时抓取平台报价；打开外卖平台不会自动下单。公开演示无需账户登录，本机历史不作为多人共享账户。原型中展示的原生账户能力没有伪装成已接通的账号服务。
