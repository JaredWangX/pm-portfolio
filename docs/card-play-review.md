# 卡片趣味互动复核

用户希望将斜向反光换成更有趣的互动，并授权搭配点阵与图标动作。本次保留首页已确认的鼠标柔光、全站蓝色玻璃表面、排版与产品内容，只替换卡片交互。

## 设计与参考

参考 [React Bits Dot Grid](https://reactbits.dev/backgrounds/dot-grid) 的指针与弹性点阵互动思路，以及 [Codrops 关于 Phantom.land 交互网格的文章](https://tympanus.net/codrops/2025/06/30/invisible-forces-the-making-of-phantom-lands-interactive-grid-and-3d-face-particle-system/) 的网格反馈方向。本项目自行实现原生 Canvas 2D 版本，不导入 React、Three.js 或新的运行库。

- 蓝色点阵只在鼠标当前所在卡片出现，附近的点随指针让开，移开后回位淡出。色彩与玻璃表面保持一致，卡片和文字本身不跟随鼠标旋转或移动。
- 文字、控件、截图、视频和 iframe 所在区域从画布中排除，位移后的点也不会进入这些区域。文档目录和正文规则块不加入点阵，只在流程展示区保留互动。
- 首页四个能力图标分别使用勾选描画、芯片点亮、对话回复和指南针转动。前三项为进入卡片后的短动作；指南针随鼠标横向位置改变方向。
- 保留原生鼠标指针和已有点击行为。没有自动游走、拖尾、点击冲击波或循环重播。

## 实现约束

全页复用一个 Canvas 和一个活动动画循环，画布不超过约 100 万像素，点阵数量上限约 650。静止收敛后不继续绘制。离开卡片时回位淡出；滚动、窗口失焦、页面隐藏、调整尺寸或卡片因内容加载改变尺寸时清除画布，避免使用旧坐标。

触屏、减少动态效果和减少透明度偏好下关闭点阵，保留内容与操作。减少动态效果时图标保持静止。沿用现有清晰的键盘焦点标识。

## 验证记录

浏览器脚本及截图保存在忽略目录 `work/playful-cards/`。覆盖首页、两个项目案例、两篇 PRD、两篇复盘：

- 移动指针后画布内容改变；停止后绘制次数稳定；离开、滚动和减少动态效果设置会清除活动画布。
- 同一时刻仅一个活动画布，卡片尺寸和位置不变。首页段落区域的画布 alpha 采样为零。
- 320、390、768、1440px 无横向溢出；实测模拟触屏不创建点阵。
- 目录跳转、PRD 折叠、图片放大关闭可用，四个能力图标按预期回应。
- 初始内容保护范围曾覆盖整个列表行，导致 PRD 流程图中的互动被全部抹除；现按正文块与实际文本行排除，既保留空隙里的点阵，也保护文字。

七页正文、导航链接保持原样。未修改产品应用内部或后端；移动端验证采用浏览器触屏模拟，未作真实低端设备性能保证。

按 `talos-docs/SOP/web/web-dev` 的截图流程检查七页桌面与手机布局，并实际查看截图。通用悬停选择器曾命中视口外的首个卡片，属于截图动作定位问题；首页改用能力卡片，PRD 改用流程标题并等待锚点滚动完成，再复核互动。浏览器专项检查另行验证每页的实际画布响应，不以截图脚本退出成功代替互动验证。

截图工具提示的流程分支侧线用于区分异常路径，英文大写项为 Prompt 合约标识；标题旁的短标签保持原有分组关系。这些提示不属于可读性错误，保留既有信息结构。未发现运行时异常、横向溢出或失效图片。Taste 完整设计门禁未启用，本记录不声称通过该门禁。

当前桌面 Chrome 连续鼠标运动采样中，帧间隔 P95 为 16.7ms，超过 50ms 的采样帧为 0；同一时刻仅一个活动画布。该结果仅覆盖本次浏览器和页面状态，不代表真实手机或所有硬件的性能。
