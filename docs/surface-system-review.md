# 全站矩形样式与互动复核

范围为首页、Wanso 和 ONENTRA 案例、两篇 PRD、两篇复盘，共七页。用户已确认的柔光背景保留，产品截图、手机和电脑的设备外形不改动。

## 统一规则

七页共 184 个展示容器明确标记 `data-surface`。主卡片与截图外框采用 24px 圆角，内层卡片、表格和阅读控件采用 16px；手机分别为 20px 与 14px。边框、阴影、玻璃色调、悬停反馈复用同一组变量。正文容器与表格保持安静，结果节点继续使用蓝底白字表达完成状态。

同一层级的按钮采用统一圆角、字号和最小高度。鼠标悬停不再让整个链接卡片上下移动；键盘焦点保留清晰轮廓，点击复制邮箱不会给整张联系卡片留下额外描边。独立的案例流程卡片、延伸阅读入口、引导展示区等此前未覆盖的区域现在使用同一套规则。

## 动效处理

鼠标事件只保存最新位置，在下一动画帧统一处理，避免高频输入重复写入样式。指南针变量只写到图标本身；进入状态没有变化时不重复设置卡片 class。文字保护区域在进入卡片时合并为一个路径，每帧一次擦除，替代逐个矩形擦除。

继续只保留一个活动画布。鼠标静止后停止绘制，离开回位淡出；滚动、改变尺寸、页面隐藏时清除失效坐标。触屏和减少动态效果模式关闭点阵。没有添加依赖或持续运行的后台动画。

## 验证与限制

- 七页检查 1440、768、390、320px 布局，逐个读取容器圆角验证统一规则，没有横向溢出；交互、文字遮罩、停止绘制、减少动态效果和触屏降级通过。
- 检查原有目录跳转、折叠、图片放大、邮箱复制及新增链接。正文和原有内容对比保持一致，只有联系信息与论文入口文案发生变化。
- 截图依据 `talos-docs/SOP/web/web-dev`，实际查看联系区、案例、能力卡片和文档截图。工具未报告控制台异常、失效图片或横向溢出。眉标与标题距离用于保持同组关系；章节编号用于长文导航；侧线用于异常分支或结论提示，因此保留相关建议提示。
- 在同一台桌面 Chrome、同样页面与鼠标路径下，旧版和新版帧间隔 P95 均约 16.8ms；新版本轮没有超过 50ms 的采样帧，绘制回调 P95 从约 0.7ms 变为 0.5ms。输入合并测试中，500 次指针事件只产生一次图标样式更新。
- 首轮非对照采样曾出现 33.3ms 的 P95 和一帧超过 50ms；之后等字体、图片和滚动稳定再进行上述同条件对比。测试结果受本机负载影响，不作为所有设备稳定帧率的保证。手机采用浏览器模拟，未做真机性能测试。
