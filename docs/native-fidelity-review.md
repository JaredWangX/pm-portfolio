# 作品集：原版页面核对与玻璃布局修订

本次修改只涉及作品集展示层和 Wanso 浏览器体验，不改 Talos 或模型服务。主色保持蓝色；保留两个案例、完整需求文档、验证记录、个人经历与联系方式。

## 页面依据

对照了本机 Wanso Android 应用的实际首页和源码 `HomeScreen.kt`、`ExploreScreen.kt`、`ProfileScreen.kt`，以及仓库内原作品集截图：`wanso-home.webp`、`wanso-explore.webp`、`wanso-compare.webp`、`wanso-profile.png`。首页恢复为位置与历史、AI 输入、横向推荐、最近搜索；探索页恢复为大图、双平台摘要、餐厅推荐与用餐场景；个人中心恢复口味档案和设置分组。

比价页的八行烤鸡餐品及两平台金额来自原作品集第 14 页，作为独立原型样例展示。点击餐品后可以核算份数、配送费与优惠，计算器不把原型样例当成实时平台报价。汉堡推荐、烤鸡比价与河粉优惠属于不同场景，未合并成同一订单。

浏览器体验仍使用已保存的历史菜单，并未恢复原 Android 应用的实时推荐服务；不会补造评分、距离或配送时效。账户与安全入口管理本机体验数据，不声称已登录真实平台。通知设置控制应用内的结果提醒，不发送系统推送。资料说明集中在个人中心“关于此体验”，避免每张卡片重复提示。

## 版式与交互

电脑和手机使用共同的标题、分段按钮、设备展示和底栏轨道，设备保持各自比例。案例、文档和优势卡片分别统一间距与高度，卡片内部的标题、证据和链接也对齐。平板文档改为单列；小屏保留手机优先和独立内屏滚动。

移除作品编号、重复场景说明、电脑区额外的流程块、卡片页脚关键词等装饰文案。正文、原有项目事实及详细文档保留。玻璃表面使用较轻的透明底、柔化边缘与模糊，减少多层白边和大面积饱和蓝。

背景的曲线光点与节点逐渐汇聚成网格，表现从想法到结构化方案的过程；鼠标只影响轻微位置变化，不影响文字和布局。Canvas 上限约 30 fps，页面不可见时停止，支持暂停与系统减少动态效果偏好。

## 2026-11-23：滚动重绘与产品决策文档

复现检查没有发现父页面/原型重复导航或滚动引起的布局偏移。发现全屏固定背景的 CSS 光影在离开首屏后仍然运行，而正文有 15 个实时 backdrop-filter 表面。修正将光影限制在首屏绝对定位区域；Canvas 与 CSS 动画共用可见性/暂停状态；蓝色阅读表面保留透明渐变和边缘光，不再对已柔化的背景逐块采样。固定导航保留较轻的真实模糊。滚动导航仅在当前章节变化时更新属性，长文目录活动项保持相同字重，避免因加粗改变行高。

同一 Chrome 1440×900 受控滚动检查，前后均无布局偏移和 iframe 重载；原先离开首屏仍运行的背景动画修正后暂停。一次本机采样的最长 rAF 间隔由 366.7 ms 降到 33.3 ms，仅作为该环境的诊断记录，不推广为所有设备的帧率保证。回归额外验证下滚/上滚后容器位置与高度不变、离开首屏 Canvas 不再绘制、返回首屏恢复、暂停按钮与减少动态效果继续有效。

首页“产品思考与文档”按项目分为两个对齐阅读栏，每栏包含真实品牌、任务路径、需求文档与设计复盘。移除首页满意度条形图、优惠临界点和假定耗时等分散阅读重点的展示。原项目内测数据仍保留在需求文档，注明证据局限；不把这些数据解释为某个新设计的因果效果。四篇文章加入或重写方案对比、取舍理由、验收与失败恢复、证据台账和下一轮验证计划。需求文档约 4,900 / 5,600 字，复盘约 2,800 / 2,900 字。移动端把多列表格转为带字段名的纵向条目，完整展示判断与验收内容。
