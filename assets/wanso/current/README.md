# 当前网页产品画面

本目录的 WebP 来自 `prototypes/wanso/?lang=zh` 实际运行的中文展示模式。中文导航、推荐解释、菜单说明和费用规则均由页面自身渲染；餐厅专名保留原名。默认越南语产品入口不受中文展示模式影响。

17 张画面统一采用 402 × 874 的逻辑视口、2 倍像素密度输出，文件为 804 × 1748。保留完整的手机比例、状态栏、底栏和各页独立滚动容器，没有横向压缩、覆盖生成文字或拼接新的控件。采集时固定越南时间 12:15，用于重复检查午餐场景和营业状态，不会改写线上产品时间。

- `home`、`explore`、`location`：首页、午餐探索与地图选点。
- `recommend`、`candidates`、`followup`、`confirm`：三轮选餐对话、推荐依据与五家双平台候选。
- `store`、`price`、`compare`、`menu`、`reviews`：同一家店的详情、价差结论、费用逐项比较、完整菜单和用餐建议。
- `saved`、`history`、`profile`：照片封面收藏夹与收藏餐厅首屏、会话历史、个人偏好与设置。
- `collection`、`share`：已填写但尚未提交的新建收藏夹表单、含完整菜品照片与可编辑推荐语的分享明信片；分享面板保留同份餐双平台价格和复制入口。

采集脚本为 `scripts/build_wanso_media.py`。先完整预跑，断言中文界面、首页多行输入完整可见、五家双平台精选及每轮五个候选使用不同照片、候选主卡与两平台按钮完整处于阅读区、两平台应付金额算术、优惠条款、菜单、自建收藏夹的实际保存与计数、分享页费用一致性和返回，再录制相同操作流程。每次截图前确认可见照片已加载，不截取占位色块。收藏首屏等待提示消失后采集，照片封面和两行标题使用新版实际排版；新建与分享均通过页面自身入口打开，保留真实手机外壳和弹窗。新建表单展示图标选择、名称和说明；分享画面显示完整菜品、推荐语、并排价格和粘底复制入口，优惠展开过程在视频中继续展示。

手机长页面保留真实滚动视口，不把整页内容压缩塞进一张手机。`candidates` 展示完整候选主卡，`price` 聚焦总价结论，`compare` 单独展示完整的两平台费用卡；后续说明在视频中继续滚动查看。相同餐厅在首页、推荐、详情中的照片身份保持一致。

店铺、菜单、优惠和推荐使用项目既有资料与规则，不代表平台实时价格；`reviews` 是口味与搭配建议，不是实际消费者评价。餐食图片来源见 `../catalog/README.md` 和原素材说明。原生 iOS 历史截图仍保存在 `../native/`，官网原图仍保存在 `../official/`，均未覆盖。
